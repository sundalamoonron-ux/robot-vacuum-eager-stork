An entry for make.fun's [The Robot Vacuum's Funniest Excuse](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2) bounty.

## The excuse

> "I ran out of suction, courage, and willpower, in that order. The dust won this round."

A robot vacuum owns up to missing a spot: it ran out of suction, courage, and willpower — in that order — and the dust won this round. Short, in the vacuum's own voice, and built from its own world: suction, dust, and defeat.

## Run it

```sh
python3 main.py
```

This writes the excuse line to `/output/entry.txt`.
